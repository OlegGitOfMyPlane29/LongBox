# Правила проекта
## Контекст
PasGen, веб-приложение для генерации паролей.  Flask-бэкенд + статичный фронтенд, запускается локально.
Стек: Python + Flask, JS, без внешних зависимостей кроме Flask. Всё локально.
Уровень разработчика: начинающий.

## Структура
PasGen/
├── app.py              — Flask-сервер, один API-эндпоинт /api/generate,
│                                    генерирует пароли через модуль secrets
├── requirements.txt    — Зависимости Python (только Flask 3.0.3)
├── run.bat             — Запускалка для Windows: ставит зависимости,
│                                   стартует сервер и открывает браузер автоматически
├── README.md           — Документация: быстрый старт, возможности,
│                                          сетевой доступ
├── templates/
│   └── index.html      — Единственная страница: форма настроек пароля,
│                                       индикатор силы, поле результата
└── static/
    ├── style.css       — Тема
    └── script.js       — Логика фронтенда: запросы к API, расчёт силы
                                    пароля, копирование в буфер, хранение предыдущего пароля

## Правила
- Объясняй изменения простыми словами
- Не добавляй библиотеки и фреймворки
- Не усложняй без необходимости
- Не меняй файлы, которые не относятся к задаче
- Если нужно изменить что-то за пределами задачи — сначала скажи что и зачем
- Код должен быть понятен новичку
- Генерацию паролей реализовывать только через модуль secrets, не через random
